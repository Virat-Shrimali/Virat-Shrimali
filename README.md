## 🚀 Featured Projects

### 📚 Evidence-Backed RAG

A production-oriented **retrieval-augmented generation system** designed around one principle: answers should be backed by verifiable evidence.

**What I built:**

* Dense semantic retrieval using sentence embeddings
* Sparse retrieval using **BM25**
* **Hybrid retrieval with Reciprocal Rank Fusion (RRF)**
* **Cross-encoder reranking**
* Chunk-level citations and provenance inspection
* Evidence-sufficiency checks with deterministic refusal
* Retrieval evaluation using **Recall@K, Precision@K and MRR**
* RAG evaluation and benchmarking across retrieval strategies
* **FastAPI** backend + **Streamlit** interface
* Dockerized deployment and automated tests / CI

**Result:** hybrid + cross-encoder retrieval achieved **95.45% Recall@5** on the project's benchmark, compared with 77.27% for BM25-only retrieval.

→ [Repository](https://github.com/Virat-Shrimali/evidence-backed-rag) · [Live Demo](https://evidence-backed-rag-viratns05.streamlit.app/)

### ⚡ SmartGrid — Data Imputation & Experimentation Dashboard

A modular Python package and Streamlit dashboard for studying missing-value imputation in electrical time-series data.

Implemented and compared:

`Median` · `LOCF` · `KNN` · `Makima` · `PCHIP` · `MICE` · `MissForest`

The project includes:

* Synthetic MCAR missing-data generation
* Modular imputer architecture
* MAE, RMSE, Relative Error and MAPE
* Runtime benchmarking
* Static and interactive visualizations
* Automated experiments across different missing-data rates
* Unit tests and reusable Python components
* A no-code Streamlit experimentation interface

→ [Repository](https://github.com/Virat-Shrimali/smartGrid---Data-Imputation-techniques-streamlit-dashboard) · [Live Demo](https://smartgrid---data-imputation-techniques-app-dashboardgit-cutktt.streamlit.app)

### 🧩 The Almost Impossible Chessboard Puzzle

A two-player puzzle based on a classic **information-encoding problem**.

One player observes a hidden key location and must communicate it to another player by flipping exactly one coin on an 8×8 board.

I turned the mathematical puzzle into a playable web application using:

`React` · `JavaScript` · `Node.js` · `HTML/CSS`
